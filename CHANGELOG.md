# Changelog

## 0.1.0

First release.

- Read-only decoded view for `.properties` message bundles (`\uXXXX` only; URL encoding and other escapes untouched)
- Decoded diff against HEAD, single file and all changed bundle files
- Message search across all locales and keys, with copy key / find usages
- Inline messages, hover with every locale and missing translations, go-to-definition for keys in JSP / JS / Java
- Sync command for generated bundles
- English and Korean UI
